# Digital Artist Portfolio

React + Vite + Three.js portfolio, deployed on Vercel.

**Content is edited without code** through the editor at `/admin/` (Decap CMS).
See [HOW-TO-ADD-PROJECTS.md](HOW-TO-ADD-PROJECTS.md) for the editing guide and the one-time setup.

```bash
npm install
npm run dev     # site
npm run cms     # local editor backend (then open /admin/index.html)
npm run build
```
